# 🏍️ Roca Motos RL - Sitio Web & Catálogo Virtual

Aplicación web para **Roca Motos RL**, enfocada en el catálogo de repuestos y accesorios de motocicletas de alta rotación, con integración directa a WhatsApp business para consultas y ventas.

---

## 🚀 Tecnologías Utilizadas

* **Frontend:** React + Vite, Tailwind CSS, React Router DOM.
* **Backend / CMS:** Sanity Studio (Headless CMS).
* **Despliegue:** Vercel (Frontend) & Sanity Cloud (Backend).
